# C++ Programming Assignment

## Questions

1. write a program with a class called Person, with data members age and height, that has all constructors defined including a copy constructor. Create an array of objects of type Person, populate the array and individually identify the 'persons' with maximum age and maximum height.

2. Write a program that has a class called complex to present a complex number. Overload the + and - operators to add and subtract two complex numbers respectively.

---

## Example Test Cases & Expected Outputs

### Question 1 (`q1`)

**Sample Input:**

3
25 175.5
30 160.0
22 182.0

**Expected Output:**

Person with Maximum Age: Age = 30, Height = 160
Person with Maximum Height: Age = 22, Height = 182

---

### Question 2 (`q2`)

**Sample Input:**

3 4
1 2

**Expected Output:**

Sum: 4 + 6i
Difference: 2 + 2i
